# Simple Interest Calculator

A simple Bash shell script that calculates simple interest based on the principal amount, annual rate of interest, and time period in years.

## Formula

**Simple Interest = (P × R × T) / 100**

Where:

- **P** = Principal amount
- **R** = Annual rate of interest (percentage)
- **T** = Time period in years

## Usage

Make the script executable and run it:

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

Enter the principal amount, annual rate of interest, and time period when prompted.

## Project Purpose

This open source project demonstrates a simple financial calculator implemented as a Bash script. It is intended as a learning example for Git, GitHub, shell scripting, and collaborative development.
